# 🧮 Calculator

A fully responsive, modern calculator web application with secure computation and beautiful UI.

## ✨ Features

- **Secure Calculation** - Safe expression parser (no eval())
- **All Operations** - Addition, Subtraction, Multiplication, Division, Percentage
- **Responsive Design** - Works perfectly on mobile, tablet, and desktop
- **Keyboard Support** - Use keyboard shortcuts (Enter, Backspace, Escape)
- **Clean UI** - Modern dark theme with gray buttons
- **Error Handling** - Auto-clear on errors
- **Decimal Support** - Full decimal number support

## 🎮 Usage

1. Click buttons to enter numbers and operations
2. Press `=` or Enter to calculate
3. Press AC to clear display
4. Press Del or Backspace to delete last character
5. Press Escape to clear all

## 🔧 Keyboard Shortcuts

| Key | Action |
|-----|--------|
| 0-9 | Enter numbers |
| + - * / | Operations |
| Enter or = | Calculate |
| Backspace | Delete last |
| Escape | Clear all |
